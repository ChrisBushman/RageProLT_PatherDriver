FIRST LIGHT
===========

A from-scratch OpenGL driver for the ATI Rage LT Pro, rendering a gouraud
triangle on a PowerBook G3 Lombard under Mac OS X 10.3 -- loaded through the
OpenGL framework's own bundle mechanism (CFBundle), end to end:

  CFBundleCreate/LoadExecutable  Mach64GLDriver.bundle   (framework's loader)
  gldInitializeLibrary
  gldChoosePixelFormat(attribs) -> pf     rc=0
  gldCreateContext(pf)          -> ctx    rc=0, kext connect=0xd0f
  gldUpdateDispatch(ctx, table) -> table[0x28] = mach64_render_triangles
  table[0x28](ctx, verts, 3)              (GLEngine's exact call path)
     -> decompose -> mach64_read_vertex (recovered 0x100 gli layout)
     -> mach64_draw_triangle -> m64_emit -> LE writeout
     -> new_vertex_buffer -> KEXT rotateCommandBuffer -> bus-master DMA ring
     -> mach64 setup engine -> gouraud pixels
  gldFinish ; gldDestroyContext ; gldDestroyPixelFormat
